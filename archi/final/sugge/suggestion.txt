Virtual Memory is a sophisticated memory management technique that creates an illusion for an application that it has a large, contiguous block of main memory (RAM), even if the physical RAM is limited and fragmented. It bridges the gap between the speed of physical RAM and the capacity of secondary storage (like an SSD or HDD). ​When a program runs, the CPU generates virtual addresses. These addresses do not point directly to physical locations in the RAM. Instead, they are intercepted by a hardware component called the Memory Management Unit (MMU). The MMU translates these virtual addresses into physical addresses using a mapping structure called a Page Table.
